# Toolbox for Toolbox: standards

Generated by `toolbox report portal -o standard` from the portal's manifest; regenerate it, don't edit it. Toolbox is the box these standards are carried in; the tools that check them run on their own too (each record's `command`).

## Agent instruction files

Each agent instruction file: one canonical AGENTS.md with aliases pointing at it, links and commands that work in CI, and no hidden text or credentials (D75, D82, D83).

Scorecard `maintainer-agent-doc` over `AgentDoc` entities, owned by group:maintainers. `toolbox report` lists what fails now.

| Rule | Level | Passes when | Fix |
|---|---|---|---|
| `single-source` | bronze | `entity.canonical \|\| entity.pointsAtAgents` | Keep instructions in AGENTS.md. An alias such as CLAUDE.md should link to it, not restate a second set of rules. |
| `links-resolve` | bronze | `entity.missingFiles.size() == 0` | Fix or remove the relative links in the evidence. An agent follows them. |
| `has-commands` | silver | `!entity.canonical \|\| entity.commandLines > 0` | Name the build or test command in AGENTS.md (cargo, npm, pnpm, yarn, pytest, or toolbox). An alias inherits the canonical file's commands. |
| `within-budget` | silver | `entity.lines <= 500` | Keep the file under 500 lines. Move detail into a linked document. The agents.md v1.1 proposal uses 500 lines as the point where a file should be split. |
| `names-the-decision-log` | gold | `!entity.canonical \|\| entity.mentionsDecisions` | Link the canonical AGENTS.md at the decision log, so an agent edits the log instead of treating this file as the only source of truth. |
| `checks-run-in-ci` | gold | `!entity.canonical \|\| entity.ciMissingCommands.size() == 0` | Run each command in the evidence from a GitHub Actions workflow, or remove it from the check procedure. Commands that appear only in a markdown table are the track index and are not required. |
| `no-hardcoded-secrets` | bronze | `entity.secretHits.size() == 0` | Remove the credential in the evidence. An instruction file is loaded into the agent's prompt. |
| `no-hidden-instructions` | bronze | `entity.hiddenChars == 0` | Remove zero-width and other default-ignorable characters, bidi controls and variation selectors outside emoji from the file. They are invisible to a reviewer and visible to a model. |

## Commands

Run from the repository root.

| To | Run |
|---|---|
| List every failure, with path, fields, measure, evidence and fix (JSON) | `toolbox report portal -o failures` |
| Gate: exit 1 when anything got worse than the baseline | `toolbox report portal --baseline portal/results.json` |
| What this branch changed, against its base | `toolbox report portal --against origin/main` |
| Record improvements (commit the file) | `toolbox report portal --baseline portal/results.json --update` |
| Change a standard on purpose (new pattern, lower limit) | `toolbox report portal --baseline portal/results.json --update --accept maintainer-agent-doc` |
| Campaign progress since its start | `toolbox campaign --portal portal --baseline portal/results.json` |
| See exactly what a tool ran, to run it alone | `toolbox connector records --portal portal --name <connector>` |

`--baseline` alone fails only on regressions. `--ci` also fails when the baseline is out of date (an improvement not yet recorded), so the committed file always matches the code.

## CI

```yaml
# .github/workflows/toolbox.yml
name: toolbox
on:
  pull_request:
  push: {branches: [main]}
permissions: {contents: read}
jobs:
  report:
    runs-on: ubuntu-latest
    steps:
      # Pin both to a full commit SHA, with the tag in a comment (zizmor's unpinned-uses).
      - uses: actions/checkout@<sha> # v6
        with: {persist-credentials: false}
      # The tools the portal pins must be installed first: `toolbox tools install` or your
      # installer, from the versions under `tools:`; the action runs `toolbox doctor`.
      - uses: loganvolkers/toolbox/actions/report@<sha> # <version>
        with:
          toolbox-version: "<version>"
          portal: portal
          baseline: portal/results.json
          mode: ci    # or check: fail on regressions only
```
