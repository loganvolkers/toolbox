Seikika draws on these projects and their public work.

- **Betterer** showed how to save baseline results in Git and review improvements alongside code. [Seikika and Betterer](/compare/betterer/)
- **Backstage** showed how a portal can bring service ownership, documentation, and plugins together. [Seikika and Backstage](/compare/backstage/)
- **OpenSSF Scorecard** made supply chain checks available through one tool with public explanations for each score. [Seikika and OpenSSF Scorecard](/compare/openssf-scorecard/)
- **Port Ocean** showed how integrations can collect outside data and map it into a catalog. [Seikika and Port](/compare/port/)
- **SARIF** gives static analysis tools a shared way to report findings. [Linters and formatters](/compare/linters-and-formatters/)
