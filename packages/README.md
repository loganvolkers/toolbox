# Seikika standards packages

Add these packages to a portal manifest to reuse checks. Each README describes
what the package checks, the inputs it needs, and how to adopt it. Start with
[Gate pull requests](https://seikika.com/operators/ci/) for a complete repository
setup or [Share standards](https://seikika.com/authors/) to publish your own.

| Package | What it checks |
| --- | --- |
| [file-size](file-size/README.md) | Files that exceed a line limit |
| [github-actions](github-actions/README.md) | Workflow security, reliability, and supply chain |
| [openssf-scorecard](openssf-scorecard/README.md) | Results from OpenSSF Scorecard |
| [pattern-count](pattern-count/README.md) | Matches for a text pattern in files |
| [pnpm-expo](pnpm-expo/README.md) | pnpm workspace and Expo project setup |
| [sarif](sarif/README.md) | Findings from tools that emit SARIF, a standard results format |
| [semgrep](semgrep/README.md) | Findings from Semgrep rules |
| [sre](sre/README.md) | Production readiness for a service |
| [storybook](storybook/README.md) | Storybook catalog setup |
