# Seikika standards packages

Add these packages to a portal manifest to reuse checks. The public
[standards package directory](https://seikika.com/packages/) lists the
packages with setup and verification guides. Each directory here has the
package manifest, the fragments it adds, and a test portal.

Start with [Gate pull requests](https://seikika.com/operators/ci/) for a complete
repository setup or [Share standards](https://seikika.com/authors/) to publish your own.
