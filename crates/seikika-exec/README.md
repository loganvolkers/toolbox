# seikika-exec

Runs Seikika self-service actions. It handles previews, confirmation, execution, and
verification, and supports approval grants between portals.

This Rust crate is part of the Seikika framework. Use it when maintaining Seikika's
internals.

## Where to start

Operators and users can start with the action guide. Callers provide storage and access
control around the run lifecycle.

- [Test and run an action](https://seikika.com/users/actions/)
- [Rust API source](https://github.com/seikika/seikika/blob/25a208a3bc1a97f184588c512afcb12d636ce7be/crates/seikika-exec/src/lib.rs)
- [Build and check Seikika](https://seikika.com/start/run/)
