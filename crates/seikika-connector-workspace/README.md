# seikika-connector-workspace

Reads a local checkout and reports facts such as Rust workspace members, Markdown links,
and GitHub Actions workflows.

This connector brings data from its source into a Seikika portal. Use the binary
with the matching Seikika release or build both from the same source checkout.

## Use the connector

This connector reads checkout data for repository scorecards. Use the repository
quickstart to verify it and see the Markdown link check in action.

- [Install Seikika and connectors](https://seikika.com/start/install/)
- [Set up and check a connector](https://seikika.com/start/quickstart/)
- [Connector source and tests](https://github.com/seikika/seikika/blob/25a208a3bc1a97f184588c512afcb12d636ce7be/crates/seikika-connector-workspace/src)
