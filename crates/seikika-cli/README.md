# seikika-cli

This package builds the `seikika` binary. Use the command line to check standards
in a repository, serve a portal, or work with its catalog and actions.

## Get started

Follow [Install Seikika](https://seikika.com/start/install/) to choose a release
or build from source. Run `seikika --version` to confirm the binary is available
and see the installed version.

- [Score a practice repository](https://seikika.com/start/quickstart/)
- [Explore a local portal](https://seikika.com/start/portal/)
- [CLI reference](https://seikika.com/start/cli/)
