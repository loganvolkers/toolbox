# seikika-derive

Turns a consistent snapshot of raw inputs into catalog entities, relations, and scores. It
also compares derived states for plans and checks manifest fixtures.

This Rust crate is part of the Seikika framework. Use it when maintaining Seikika's
internals.

## Where to start

Start with the catalog guide to follow a record through the pipeline. The reference portal
fixtures provide expected outputs for maintainers.

- [How the catalog works](https://seikika.com/concepts/catalog/)
- [Rust API source](https://github.com/seikika/seikika/blob/25a208a3bc1a97f184588c512afcb12d636ce7be/crates/seikika-derive/src/lib.rs)
- [Build and check Seikika](https://seikika.com/start/run/)
