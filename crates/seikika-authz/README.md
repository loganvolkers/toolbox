# seikika-authz

Identifies callers and checks what they can access in a portal. It defines the
authorization interface, supports an OpenFGA process for shared portals, and provides
local checks for fixtures.

This Rust crate is part of the Seikika framework. Use it when maintaining Seikika's
internals.
