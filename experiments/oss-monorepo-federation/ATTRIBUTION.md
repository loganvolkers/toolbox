# Attribution

Vendored sparse fixtures under `leaves/*/fixtures/` are excerpts from public MIT-licensed
repositories. Full project copyright remains with the upstream authors. Each leaf directory
includes that project's `LICENSE` text.

| Leaf | Upstream | License file |
|---|---|---|
| babel | https://github.com/babel/babel | `leaves/babel/fixtures/LICENSE` |
| jest | https://github.com/jestjs/jest | `leaves/jest/fixtures/LICENSE` |
| pnpm | https://github.com/pnpm/pnpm | `leaves/pnpm/fixtures/LICENSE` |

Pinned observation date for mined conventions: **2026-11-21** (default branch `main`).
Large configs are replaced by `*.evidence.json` stubs (presence + SHA-256 + head bytes) so the
experiment stays small; scorecards assert presence, not full-file contents.

This experiment does **not** redistribute those projects' source trees.
