Use **Toolbox**, with GitLab as its code host. Its binaries are in `{DEST}/bin`, and the runner's jobs have the same binaries on their `PATH`. Its documentation is in `{DEST}/toolbox-docs`: the agent skills in `skills/` (one per command), two example portals in `examples/`, and the manifest's JSON Schema, `manifest.schema.json`. `toolbox --help` and `toolbox <command> --help` also work. Write whatever glue Toolbox doesn't provide yourself, in any language. You may install packages.
