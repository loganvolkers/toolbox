Use **Backstage**. A Backstage 1.57 app, created with `@backstage/create-app` and with the scaffolder backend installed, is at `{DEST}/backstage`. Node 24 and yarn are in `/tmp/bs/node24/bin`; add that directory to `PATH`. Start the backend with `yarn workspace backend start` in `{DEST}/backstage`. It listens on http://localhost:{PORT} (set in `app-config.local.yaml`). The same file gives each person a static token (`ann-token-0123456789`, `bob-token-0123456789`, `carol-token-0123456789`, `dave-token-0123456789`, `erin-token-0123456789`) through `backend.auth.externalAccess`: Backstage authenticates each as an external service principal whose subject is the person's name. Send `Authorization: Bearer <token>`. There is no GitHub here: the origins are local git repositories. You don't need the frontend; the API is enough. Backstage's documentation for this release is in `{DEST}/backstage-docs`: the `docs/` tree of backstage/backstage at v1.57.0, and the OpenAPI specs of the scaffolder and catalog backends. Write whatever glue Backstage doesn't provide yourself (custom scaffolder actions, backend modules, scripts), in any language. You may install packages.
