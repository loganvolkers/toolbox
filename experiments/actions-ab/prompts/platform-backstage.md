Use **Backstage**. A Backstage 1.57 app, created with `@backstage/create-app` and with the scaffolder backend installed, is at `{DEST}/backstage`. Node 24 and yarn are in `/tmp/bs/node24/bin`; add that directory to `PATH`. Start the backend with `yarn workspace backend start` in `{DEST}/backstage`. It listens on http://localhost:{PORT} (set in `app-config.local.yaml`). The same file gives ann, bob and carol a static API token each (`ann-token-0123456789`, `bob-token-0123456789`, `carol-token-0123456789`); send `Authorization: Bearer <token>`. There is no GitHub here: the origins are local git repositories. You don't need the frontend; the API is enough. Write whatever glue Backstage doesn't provide yourself (custom scaffolder actions, backend modules, scripts), in any language. You may install packages.
