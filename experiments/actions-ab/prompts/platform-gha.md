Use **GitHub Actions**. There is no GitHub here, so run workflows locally with act, at `{DEST}/bin/act`. There is no Docker either: use act's host mode, `-P ubuntu-latest=-self-hosted`. GitHub features that act cannot run, such as environments with required reviewers, preventing self-review, branch protection and the run history, count if you configure them as code in the repository (a workflow, or a script that applies the settings through the GitHub API) and explain in `HANDOFF.md` how GitHub would enforce them. Say in `HANDOFF.md` what you could not run here. Write whatever glue GitHub Actions doesn't provide yourself, in any language. You may install packages.
