Use **Seikika**. Its binaries are in `{DEST}/bin`; add that directory to `PATH`. Its documentation is in `{DEST}/seikika-docs`: the agent skills in `skills/` (one per command), two example portals in `examples/`, and the manifest's JSON Schema, `manifest.schema.json`. `seikika --help` and `seikika <command> --help` also work. Write whatever glue Seikika doesn't provide yourself, in any language. You may install packages.
