# D83. A check command named in AGENTS.md must appear in a workflow

**A check command named in AGENTS.md must appear in a workflow.** Extends D75. Backtick invocations of `cargo`, `npm`, `pnpm`, `yarn`, `pytest`, `python`, `fga` or `seikika` plus a subcommand, outside markdown table rows, must occur in `.github/workflows`. Table rows are the track index. An alias does not have to repeat the commands
