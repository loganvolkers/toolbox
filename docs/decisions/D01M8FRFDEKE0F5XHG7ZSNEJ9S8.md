# Stage complete child reports and reconcile catalog identities explicitly

Parents can compose committed child snapshots and build-staged report artifacts.
A source key path qualifies definitions and catalog records. An operator may
alias a child record of a declared kind to a known parent record. The canonical
row retains the parent facts and the individual child observations and scores.
Definitions, score rules, and comparison cohorts keep their source identity.

Use the same artifact for static and served reports. The maintainer loop builds
an actual child report and uses seeded parent inventory before any hosted
validation. This revises the global entity identity assumption in [D68](../design/federation.md).
[Design, evidence, and gap assessment](../design/federation-inventory.md).
