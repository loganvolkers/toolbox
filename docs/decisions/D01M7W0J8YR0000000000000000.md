# D71. Scorecards are scored too, at exactly one meta level that scores itself

**Scorecards are scored too, at exactly one meta level that scores itself.** `toolbox describe scorecards` turns portals' scorecards and rules into records (manifest facts, CEL size/nesting/fields/functions, test mentions, fixture outcomes, live outcomes as information). Toolbox for Toolbox's `meta-rule` (fix, tested, decided and both outcomes on fixtures, evidence, no nested loops, readable) and `meta-scorecard` (tested, no empty level, fixtures reach two levels, every rule tested) score its own, the starter's and the reference portal's standards, themselves included; meta rules read only deterministic inputs, so the ratchet stays a fixed point and no further level exists. `toolbox validate` rejects undeclared CEL functions. Scorecards may set `ratchet.newEntitiesAtLeast` (new entities below it are regressions; a scorecard new to the baseline baselines first). LLM assessment and agent trials are proposed, advisory and cached, never gating alone

**Status:** ✅ deterministic; 📝 LLM and trials
