# A decision is one file, and its id is a ULID

**A decision is one file, and its id is a ULID.** The log is `docs/decisions/<id>.md`, one file per decision, so two agents no longer append the same row to one table. The id is `D` plus a 26-character [ULID](https://github.com/ulid/spec): 48 bits of Unix time in milliseconds and 80 bits of randomness, Crockford base32, lexicographically time-ordered. `python3 scripts/decision-id.py` mints one. Filename order is time order. D1–D98 keep working. Each backfilled file records `legacy: Dnn`; its timestamp is the commit that introduced the row, and its random part is zero. Existing `Dnn` citations are not rewritten. Amends D84.
