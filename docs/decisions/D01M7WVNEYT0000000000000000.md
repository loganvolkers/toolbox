# D90. Distribution: Seikika is released, connectors leave core, tools are declared

**Distribution: Seikika is released, connectors leave core, tools are declared** (resolves Q16, as recommended). Seikika releases with `dist` (per-platform archives, installers, attestations), cargo-binstall metadata, an aqua registry entry and a container image. Connectors are builtin, executable (any language, pinned per platform in `seikika.lock`), WASM component (later) or remote, all gated by the conformance kit. Packages declare `tools:`; mise or aqua installs them; `seikika doctor` checks. Build order: releases → executable connectors → tools and doctor → package format → WASM
