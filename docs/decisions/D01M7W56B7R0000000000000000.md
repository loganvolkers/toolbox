# D76. npm manifests are catalogued as applications: a lockfile is the pin, and npm audit is not a gate

**npm manifests are catalogued as applications: a lockfile is the pin, and `npm audit` is not a gate.** Toolbox for Toolbox gains a `PackageJson` kind (`**/package.json`) and `maintainer-package`: bronze is a name, a private package or a version, and bounded registry ranges (no `*`, `>=`, git or tarball URL; caret and tilde stay bounded); silver is a sibling lockfile and a `test`, `build`, `check` or `typecheck` script; gold is a description, `engines.node`, and CI that does not run `npm install` for that package. A licence field is not required (Q1). A new manifest must reach bronze
