# D56. Composite REST view endpoints

**Composite REST view endpoints** (`/v1/views/home`, `entity/{id}`, `scorecard/{name}`, `ops`) and an SSE event stream serve the minimal UI and operator bundles in one request per page, instead of GraphQL. The browser UI's TypeScript is the one front-end language, counted outside D45's server-side budget
