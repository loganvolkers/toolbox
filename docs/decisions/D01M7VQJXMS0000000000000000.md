# D62. Only records and deletes create input versions

**Only records and deletes create input versions.** Control-only connector batches (register, ack, complete, log) don't, so snapshot ids change only when data does. `TOOLBOX_CONNECTORS=off` disables in-image connector supervision (fixture-driven dev and tests)
