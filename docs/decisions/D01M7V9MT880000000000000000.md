# D48. Connector control channel

**Connector control channel.** Besides the ingest endpoint, Toolbox sends connectors commands (scoped `refresh`, `resync`, `cancel`) with acknowledgements, completion and the snapshot id that contains the results. Delivered over stdio for in-image connectors, long-poll pull for remote ones (no inbound ports), optional push. Still a versioned Toolbox API, not a governed standard
