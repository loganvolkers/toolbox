# The hosted report opens on fleet health, catalogs entities, and lists every rule outcome

**The hosted `toolbox report` page is a three-mode explorer: Overview, Catalog, and Scorecards.** Overview answers whether the portal is healthy before any scorecard is selected. Catalog lists every derived entity by kind. Scorecard and entity views list pass, fail, unknown, and skipped outcomes together, with fix and evidence still leading on failures. The report JSON includes a slim `catalog` map (`kind` → entity ids). Amends D92 and D93 for what the element renders, not how it is hosted.
