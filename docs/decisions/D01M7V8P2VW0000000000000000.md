# D45. Sprawl budget for v1

**Sprawl budget for v1** (critique C9, tightened by G1): ≤ 2 implementation languages in the default image (Rust; Go only inside the OpenFGA component), **no required runtime service besides Postgres**, ≤ 3 author-facing languages (manifest, CEL, OpenFGA DSL; TypeScript optional for the builder and UIs). Any addition needs an ADR with a measurement
