# Scope pull request assessments before invoking a delegate

The maintainer SDLC pilot selects work from changed paths and the assessment policy at the trusted base commit. The plan identifies the comparison merge base and exact head, the checks selected for that head, and questions that require judgment. GitHub CI records check evidence. A maintainer can use the same plan with a locally configured agent, subject to a durable admission ledger. Review results are advisory during the pilot.

The runner reserves each start in SQLite. Newer plans supersede older ones through a monotonic generation supplied by the runner. Start limits apply across retries and rebases. Design review has a separate stop condition based on two completed rounds without new findings. The pilot records usage when the adapter reports it and always bounds packet size, process duration, and launch rate.

New entity assessment briefs include a rubric hash. Local validation uses it when supplied and rejects duplicate verdicts. Earlier assessment files retain subject-hash freshness. The PR pilot binds results and evidence to a plan digest so the same plan can travel between the deterministic CI jobs and the review harness.
