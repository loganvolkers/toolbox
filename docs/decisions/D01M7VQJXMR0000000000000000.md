# D61. MCP is implemented in Seikika, not with rmcp:

**MCP is implemented in Seikika, not with rmcp:** a small JSON-RPC handler whose tools call the REST handlers in-process, so MCP, REST, CLI (`seikika get`/`owner`/… call the MCP tools) and the UI share one authorization and facet-shaping path. rmcp can replace it behind the same endpoint if MCP features beyond tools are needed
