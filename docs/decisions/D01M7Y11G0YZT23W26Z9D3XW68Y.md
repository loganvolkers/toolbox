# Campaigns and tracks are core: time-bound goals over scorecards, not a UI feature

**Tracks name long-term focus programs; campaigns are time-bound goals that compose existing scorecards via `includes` (level and/or rules), with derived progress.** Declared in the manifest (config-as-code). Progress is `meeting / inScope` over the intersection of non-skipped entities on every included scorecard. Surfaces: derive, report JSON, hosted report Campaigns mode, CLI, API, MCP, and the minimal UI. Amends the Phase 2 "initiatives" sketch in [plan.md](../plan.md) and the hosted-report modes in D01M7XY1QYKW2D0HMSG50R0XTQH.
