# D55. Neither the builder nor build resolves environment variables or secrets

**Neither the builder nor `build` resolves environment variables or secrets.** `${env:…}` and `${secret:…}` stay placeholders until server start-up, so one manifest serves every environment and a CI plan is valid for production
