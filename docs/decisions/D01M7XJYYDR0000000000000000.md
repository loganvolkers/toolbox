# D97. Tracked YAML is formatted by Yamark 0.6.1

**Tracked YAML is formatted by Yamark 0.6.1.** `compact` keeps a collection that fits in 80 columns in flow style, which is the rule for the JSON Schema objects embedded in manifests; a wider collection is a block. CI runs `yamark format --check` on every tracked `.yaml` and `.yml`. Markdown and `schema/*.json` are not rewritten: the compiler loads those schemas as JSON. Plain timestamps are strings (YAML 1.2); the reference tools drop PyYAML's 1.1 timestamp resolver so they agree
