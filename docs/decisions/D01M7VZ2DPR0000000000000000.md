# D70. GitHub Actions are catalogued and scored, built on zizmor and actionlint rather than re-implemented

**GitHub Actions are catalogued and scored, built on zizmor and actionlint rather than re-implemented.** Toolbox for Toolbox gains `Workflow` and `ActionDependency` kinds and three scorecards: `maintainer-ci-security` (actionlint clean; no high zizmor findings; least-privilege token; SHA-pinned; then no medium findings and no write tokens on risky triggers; then zizmor-clean), `maintainer-ci-reliability` (main not red 3+ runs; fail rate ≤ 20/10/5%; job timeouts; ≤ 5% re-runs; superseded runs cancelled; p90 ≤ 15 min) and `maintainer-action-deps` (SHA-pinned everywhere). Generic connector support: `workspace` parses workflows (`workflows` globs), `runner` runs zizmor/actionlint (`optional`), `github` summarises run history (`actions`). Rules over missing tool data are `unknown` (never a regression; `--ci`/`--update` refuse); run history is time-varying and excluded from the ratchet. Thresholds for reliability are Toolbox proposals, not a published standard
