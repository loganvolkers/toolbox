# D92. The public site publishes this repository's own toolbox report

**The public site publishes this repository's own `toolbox report`.** `site/public/report/index.html` is the one-file HTML report (D66), and a docs page links to it. CI checks that file against a fresh `toolbox report portal --skip runner,github-actions`. The report is the demo of the maintainer SDLC on this repo. It applies no facets, which is the caveat in repo-portals §4 for a repo whose readers can read the repo
