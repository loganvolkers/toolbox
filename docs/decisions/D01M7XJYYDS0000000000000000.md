# D98. release.yml stays the bytes dist generates

**`release.yml` stays the bytes `dist` generates.** `dist plan` fails when that file differs from the generator, which is what a Yamark pass does. The formatter check excludes `.github/workflows/release.yml`. Every other tracked `.yaml` and `.yml` is still checked (D97)
