# D33. Charter goal G1, simple deployment

**Charter goal G1, simple deployment.** The default deployment is **one container image plus Postgres**, runnable on Google Cloud Run or an equivalent. Custom UIs and self-service action code ship *inside* that image, not as separate pods or microservices. Modular deployment (split roles, external services) is optional, never required
