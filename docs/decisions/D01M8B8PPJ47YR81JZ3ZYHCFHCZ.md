# Name the project Seikika

Seikika is the project name and `seikika` is its shared identifier. The name comes from the
Japanese computing term for normalization, which describes how the portal brings records from
different tools into a common catalog.

Use `seikika` for the CLI and project repository, `seikika-*` for Rust crates and release
artifacts, and `@seikika` for public npm packages. Use the Seikika name in configuration
files, connector and action protocols, API headers, environment variables, schemas, and docs.
The renamed distribution starts with the next release and consumers use the new identifiers
when they upgrade.

Use `seikika/seikika` for the GitHub repository, `ghcr.io/seikika/seikika` for the
container image, and `https://seikika.com/` for the docs, report, and Storybook. Use
`seikika.com` as the namespace for manifest versions, schema IDs, and API problem types.
GitHub repository settings and package publisher ownership are managed separately from the source tree.
