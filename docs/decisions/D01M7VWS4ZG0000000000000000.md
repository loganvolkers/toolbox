# D66. Scorecards say why, at fleet and repo scale

**Scorecards say why, at fleet and repo scale.** Rules may carry an `evidence:` CEL expression, evaluated when they fail and shown with the fix everywhere scores are shown. `scorecard_report` (MCP), `toolbox scorecard` and `/v1/scorecards[/{name}]` give one scorecard across entities; `query` filters can read `scores`. `toolbox report` scores a repository with no server (in-image connectors run once), prints md/json/one-file HTML, and ratchets against a committed baseline in the manner of Betterer: a newly failing rule or growing evidence is worse; `--ci` also fails when the baseline is stale. Also: dropped-relation diagnostics (`unresolved: ignore` to opt out), refresh results that list what changed, `TOOLBOX_MCP_TRACE` for observed MCP calls. This repo's CI gates on `portal/results.json`
