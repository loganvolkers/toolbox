# D93. The HTML report is a custom element with slots

**The HTML report is a custom element with slots.** `<toolbox-report>` renders the scorecards in a shadow tree. A host page projects light-DOM children into the slots `header`, `nav`, and `footer`. `-o html` is still one file, with the element and the data inlined. `-o web --out DIR` writes `toolbox-report.js`, `report.json`, and that page, so a site can load the element and fill the slots. The host's markup is not concatenated into the report
