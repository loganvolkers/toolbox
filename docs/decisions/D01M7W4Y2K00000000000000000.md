# D75. Agent instruction files are catalogued, with AGENTS.md canonical and aliases required to point at it

**Agent instruction files are catalogued, with AGENTS.md canonical and aliases required to point at it.** Toolbox for Toolbox gains an `AgentDoc` kind (`AGENTS.md`, `CLAUDE.md`, `GEMINI.md`) and `maintainer-agent-doc`: bronze is a single source of instructions whose relative links resolve; silver is a test or build command in the canonical file and at most 500 lines (the agents.md v1.1 proposal's guideline, not a required field); gold is a link to the decision log plus no secret shapes and no hidden characters. Frontmatter stays optional. Judging the prose is not a gate. A new file must reach bronze
