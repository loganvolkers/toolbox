# D74. Direct Cargo dependencies are catalogued from the manifests and the lockfile; advisories are not a gate

**Direct Cargo dependencies are catalogued from the manifests and the lockfile; advisories are not a gate.** Toolbox for Toolbox gains a `Dependency` kind (`"dependencies": true`) and `maintainer-dependency`: bronze is a bounded requirement from a registry (no `*`, no `>=`, no git); silver is one version in `Cargo.lock`; gold is that a crate used by more than one member is declared in `[workspace.dependencies]`. Dev-dependencies are not entities. OpenSSF vulnerability probes, `cargo deny` licence allow-lists and RustSec need a database and a licence policy (Q1) and do not gate. A new dependency must reach bronze
