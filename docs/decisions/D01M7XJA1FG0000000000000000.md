# D96. The ratchet's verdict is data, for any pipeline

**The ratchet's verdict is data, for any pipeline.** `toolbox report --verdict FILE` writes `toolbox-verdict/v1` on every run, errors included: `result` (`pass`, `regressed`, `stale`, `missing-baseline`, `unknown`, `error`), `exitCode` (0, 1, 2, unchanged), `mode`, `baseline`, `written`, `unknownRules`, and each regression, improvement and change as `{scorecard, entity, message}`. The `actions/report` action reads it for its outputs and for one annotation per regression, instead of matching stderr text; GitLab, Jenkins and other pipelines read the same file. The failing path is tested end to end, in the CLI and in CI's pilot job
