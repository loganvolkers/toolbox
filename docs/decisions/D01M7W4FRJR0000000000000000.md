# D73. First-party connectors are catalogued and scored from the source tree; runtime health is not a gate

**First-party connectors are catalogued and scored from the source tree; runtime health is not a gate.** Toolbox for Toolbox gains a `Connector` kind from `crates/toolbox-connector-*/Cargo.toml` and `maintainer-connector`: bronze is a description, crate docs that name the config, and `run_stdio` or `run_remote`; silver is named record kinds, `snapshot_complete` and `not_found` (a push-only connector is exempt) and at least one unit test; gold is a CI conformance line (or an acceptance script for a push connector) and no hardcoded secret shapes. Airbyte's credentialed acceptance suite, Singer's runtime SCHEMA messages and the meta-catalog's lag and error-rate rules need a live system and do not gate. A new connector must reach bronze
