# D87. SDLC has four layers: package author joins maintainer, operator and user, and every layer's stages are catalogued and scored

**SDLC has four layers: package author joins maintainer, operator and user, and every layer's stages are catalogued and scored.** The package author SDLC (anyone publishing packages, connectors or standards for others) follows the maintainer loop to *test*, then forks: test against released Toolbox versions and platforms, then package, distribute and adopt. Toolbox for Toolbox declares each layer's stages as data (`portal/sdlc/`: exit criterion, commands, checks, docs, status, gaps), read by the workspace connector's new generic `data` source (records from YAML or JSON with a content hash and `missingPaths`), and scores them with `sdlc-stage` and `sdlc-layer`, plus the advisory `review-sdlc-stage` over an `sdlc-stage-quality` rubric (executable exit, agent can complete, reuses released artifacts, decoupled from core). Binary distribution (releasing Toolbox, connectors outside core, upstream tools) is proposed, not decided (Q16)

**Status:** ✅ layer and catalog; 📝 distribution
