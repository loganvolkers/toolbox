# D86. A repository's level is the lowest constituent scorecard, not a weighted 0–10

**A repository's level is the lowest constituent scorecard, not a weighted 0–10.** `maintainer-repo` reads `cards` on a second derive pass: each constituent's level ignores unknown rules and fixture ids under `/demo/`, and the repository's level is that minimum. The constituents are declared in `policy.repoRollup` and exclude runner-backed cards, whose absent data would make the repository `none`. A fraction can be shown; it does not enter the ratchet. CI fail rate stays observational (D70)
