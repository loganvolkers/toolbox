# D63. SDLC has three layers, and documents name the one they mean

**SDLC has three layers, and documents name the one they mean.** *Maintainer SDLC*: building and verifying Seikika itself in this repo (reference-model oracle, check pyramid, executable exit criteria). *Operator SDLC*: building a portal (validate → test → plan → preview → deploy → verify). *User SDLC*: building apps and agents on a portal's context and actions (stable `/v1` and MCP contracts, reproducible reads, service identities). Amends D34/G2, which named only the operator layer
