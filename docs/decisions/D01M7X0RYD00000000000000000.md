# D91. Public docs are a Starlight site in site/, deployed to GitHub Pages

**Public docs are a Starlight site in `site/`, deployed to GitHub Pages.** Seikika for Seikika catalogues each content page (`site-page`) and scores `maintainer-site`: a title, a description and resolving links, then reachable from the sidebar and not a draft, then no secret shape. A new page must reach bronze. Building the site in a harness or a visual review is not a gate. The site is this repository's project Pages site (`base` `/seikika`). It is not the one-file HTML report (D66) and it is not a package registry (D89)
