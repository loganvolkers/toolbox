# D40. Custom UIs and actions deploy in the image

**Custom UIs and actions deploy in the image.** UI: a framework-agnostic **UI extension contract** (static bundles built by `seikika build`, mounted as ES modules or Web Components, calling the public API through a generated typed client); React + `@seikika/ui` + Storybook is the default kit (G3). Actions: **in-image executors** run as child processes over the stdio transport (any language, packaged into the image), alongside external executors (GitHub Actions, webhooks). Amends critique C7 and D31's "not framework-agnostic"
