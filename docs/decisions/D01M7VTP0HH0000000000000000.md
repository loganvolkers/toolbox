# D65. Toolbox runs on itself ("Toolbox for Toolbox")

**Toolbox runs on itself ("Toolbox for Toolbox").** A local portal in `portal/` catalogues this repo's crates, docs, scripts, tests, CLI commands and MCP tools and scores them with one scorecard set per SDLC layer. It is fed by two generic connectors, `workspace` (static: cargo metadata, syn, markdown, regex captures) and `runner` (executes: cargo test, clippy, NDJSON commands), plus `toolbox describe`. Connectors report facts; thresholds live in the manifest. It runs without Postgres or OpenFGA; CI runs its tests and prints its report (not a gate yet)

**Status:** ✅ experiment
