# D69. toolbox report ships as a GitHub Action

**`toolbox report` ships as a GitHub Action** (`actions/report`, a composite action in this repo): one step in a pilot repository scores it with its repo portal (`.toolbox/toolbox.yaml`, from `examples/repo-portal-starter`) and ratchets against `.toolbox/results.json` (modes `ci`, `check`, `update`, `report`), writes the job summary and uploads the Markdown and HTML reports. Until releases exist it builds toolbox from its own source at the pinned commit, cached by a hash of the sources. The `workspace` connector gains an opt-in `repo` record (README, LICENSE, CODEOWNERS rules and owners). This repo's CI dogfoods the action (Toolbox for Toolbox) and runs a pilot from the starter end to end. The federation package registry is not decided (Q15)
