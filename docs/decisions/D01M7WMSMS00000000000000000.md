# D81. Agent plugin packages are catalogued against Agent Plugins 1.0.0; loading them in a harness is not a gate

**Agent plugin packages are catalogued against Agent Plugins 1.0.0; loading them in a harness is not a gate.** Seikika for Seikika gains a `Plugin` kind from `plugins/*/plugin.json` and `maintainer-plugin`: bronze is the 1.0.0 schema, a legal name, a description, and skills only at `skills/<name>/SKILL.md`; silver is an `mcp.json` on the 1.0.0 schema whose stdio `command` is one token; gold is no secret in headers, no `..` path, and no secret shape. Skills stay on `maintainer-skill`. A `license` field is not required (Q1). 1.1.0 hooks are not required. A new plugin must reach bronze
