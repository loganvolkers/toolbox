# D77. JSON Schemas are catalogued as the contracts the binary compiles, not as a second validator

**JSON Schemas are catalogued as the contracts the binary compiles, not as a second validator.** Toolbox for Toolbox gains a `JsonSchema` kind (`schema/*.json`) and `maintainer-schema`: bronze is Draft 2020-12, an absolute `https` `$id`, and a root description; silver is a title and a mention in `schema.rs` or the reference validator; gold is no remote `$ref` and no secret shape. Open payload objects are not required to set `additionalProperties`. The compiler is unchanged. A new schema must reach bronze
